# Astranomiya Simulyator

Bu loyiha — interaktiv astronomiya simulyatori bo'lib, foydalanuvchilarga osmon jismlari, yulduzlar va sayyoralar haqida ma'lumot olish va ularning holatini ko'rish imkonini beradi. Loyiha React + TypeScript + Vite texnologiyalari asosida yaratilgan.

## Xususiyatlar

- Interaktiv astronomiya ma'lumotlari
- React va TypeScript bilan qurilgan foydalanuvchi interfeysi
- Vite orqali tezkor ishlash
- Supabase bilan ma'lumotlar integratsiyasi
- TailwindCSS bilan zamonaviy dizayn
- astronomy-engine kutubxonasidan foydalanish

## Texnologiyalar

- React
- TypeScript
- Vite
- TailwindCSS
- Supabase
- astronomy-engine
- Lucide React

## Loyihani o'rnatish

1. Repodni klonlang:

   ```bash
   git clone https://github.com/SolijonSolayev/astranomiya_simulyator.git
   cd astranomiya_simulyator
   ```

2. Dependensiyalarni o'rnating:

   ```bash
   npm install
   ```

3. Loyihani ishga tushiring:

   ```bash
   npm run dev
   ```

## Build qilish

Ishlab chiqarish uchun:

```bash
npm run build
```

## Tekshiruvlar

- Lint tekshiruvi:

  ```bash
  npm run lint
  ```

- TypeScript tekshiruvi:

  ```bash
  npm run typecheck
  ```

## Muhit o'zgaruvchilari

Agar loyiha Supabase bilan ishlaydigan bo'lsa, quyidagi o'zgaruvchilarni `.env` faylga qo'shing:

```bash
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
